Falta apenas ativar o painel

A estrutura foi instalada, mas as alterações ficam bloqueadas até conectar o banco D1 e definir os segredos de acesso no Cloudflare. O cardápio público continua funcionando normalmente.

1. Crie um banco D1 gratuito chamado doppio-admin no Cloudflare.

2. Vincule o banco ao Worker cardapio com o nome de binding DOPPIO_DB.

3. Configure dois segredos no Worker: ADMIN_PASSWORD (mínimo de 16 caracteres) e ADMIN_SESSION_SECRET (mínimo de 32 caracteres aleatórios).

4. Inclua a vinculação D1 no wrangler.jsonc com o ID do banco para preservá-la nas próximas publicações.

Por segurança, nunca coloque a senha ou o segredo no GitHub ou nesta conversa.
